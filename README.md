# FUSE — The Execution Layer for Bitcoin Cash DeFi

FUSE lets users, liquidity providers and independent solvers execute advanced financial operations on
Bitcoin Cash using transaction-scoped liquidity (CashScript FlashVaults), composable covenants,
verifiable financial intents, competitive solver auctions and independently verifiable execution
certificates.

> Status: under active development for BCH BLAZE 2026. See `docs/STATUS.md` and
> `docs/FEATURE-MATRIX.md` for the truthful, per-feature state. Nothing in this repository has been
> deployed to BCH mainnet yet.
