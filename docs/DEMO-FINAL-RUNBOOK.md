# FUSE judging runbook

Allow four minutes. Open the [narrated demo](https://fusebch.vercel.app/judging/FUSE-demo.mp4), [slide deck](https://fusebch.vercel.app/judging/FUSE.pdf) and [evidence index](SUBMISSION-EVIDENCE.md) before screen sharing. Download the media for offline playback. The walkthrough uses public reads and a local sandbox. Leave the wallet disconnected throughout.

| Time | Presenter action |
|---|---|
| 0:00–0:23 | Open the [landing page](https://fusebch.vercel.app). Explain how one BCH transaction can borrow, trade twice and repay. |
| 0:23–1:18 | Open the atomic transaction in the evidence index. Point to the vault continuation and the two pool continuations. Read the 1,991-sat cost and block 978214. |
| 1:18–1:43 | Show the signed auction transcript linked in the index. Both operator-run solver processes quoted 1,991 sats. The quote hash broke the tie. Show settlement in block 978237. |
| 1:43–2:25 | Play the original Cashonize pairing and approval captures in the video. Follow the public transaction link for the wallet flash, block 978246. |
| 2:25–3:11 | Open the [verifier](https://fusebch.vercel.app/verify). Use the certificate object from a corrected receipt in the index. Show the two labeled sandbox captures in the shot list for the valid and altered receipt comparison. |
| 3:11–3:54 | Show the read-only Guardian, sandbox Parallel Worlds and [SDK](https://fusebch.vercel.app/developers/sdk). Close with the presentation's integration and roadmap slide. |

Use the [timed voiceover](DEMO-VOICEOVER.md) or play the narrated video. [Shot sources](DEMO-SHOTLIST.md) let a judge check which screens were recorded during the historical wallet session. [Failover instructions](DEMO-FAILOVER.md) cover connectivity and wallet issues.
