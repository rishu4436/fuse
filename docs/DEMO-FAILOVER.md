# Demonstrating FUSE offline

| Problem | Presenter action | Evidence available |
|---|---|---|
| Production alias fails | Open the [backup alias](https://fuse-rust-eight.vercel.app). Both use the same deployment, so switch to the downloaded video if both fail. | [Offline MP4](../apps/web/public/judging/FUSE-demo.mp4) and [PDF](../apps/web/public/judging/FUSE.pdf). |
| Chain explorer, pool indexer or vault reader unavailable | Show the dated observation and say when it was recorded. Restore the live view when the source recovers. | [Raw transactions, headers and inclusion paths](../evidence/mainnet/submission/chain-audit.json). |
| Wallet disconnected or mobile pairing times out | Show the original Cashonize v0.16.0 pairing and approval images, followed by its public receipt. A judge needs no wallet. | [Wallet session](../evidence/mainnet/wizardconnect-cashonize/). |
| Live receipt verification unavailable | Open the archived corrected receipt and its recorded verification levels. Describe this as the archived result. | [Evidence index](SUBMISSION-EVIDENCE.md). |
| Sandbox unavailable | Display the paired valid and tampered screenshots and their labels. | [Shot list](DEMO-SHOTLIST.md). |
| Browser cannot play video | Present the 12 slides and read the voiceover. | [Slide deck](../apps/web/public/judging/FUSE.pdf) and [script](DEMO-VOICEOVER.md). |

For offline use, download or clone the repository before judging. A previously recorded mainnet transaction demonstrates historical execution. Current spendability requires current chain readers. Drafting an execution, signing and relaying are unnecessary for this demonstration.
